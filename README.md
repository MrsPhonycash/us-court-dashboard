# ⚖️ US Federal Court Statistics Dashboard

An interactive data visualization + AI-powered insights tool built on 
real federal court filing data from uscourts.gov (2018–2023).

## Features
- 4 key metric cards with YoY trends
- Line chart: civil, criminal & bankruptcy filing trends
- Donut chart: civil case type breakdown
- Horizontal bar: criminal offense categories
- Stacked bar: case disposition outcomes
- AI insights panel powered by Claude API

## Tech Stack
Chart.js · Vanilla HTML/CSS/JS

US Courts Annual Statistical Reports — uscourts.gov
